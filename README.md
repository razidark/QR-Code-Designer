# PixelCraft QR Studio 🌟

A premium, custom-branded vector QR code generator with real-time AI styling capabilities. This studio allows users to create highly aesthetic and functional QR codes for any purpose—from simple links to complex Brazilian Pix Pay transfers.

## ✨ Key Features

*   **Multimodal Encoding:** Supports URL, Plain Text, Wi-Fi credentials, vCard contacts, Email/SMS messages, Phone numbers, and specialized **Pix Pay**.
*   **Deep Customization:** Granular control over module shapes (Dots, Hexagons), dot scale (15%-130%), and Quiet Zone margins.
*   **AI Powered Design:** Utilize the built-in **AI Suggestion Engine** to generate professional color palettes and theme structures using simple text prompts.
*   **Scan Reliability:** Real-time diagnostic reports ensure optimal contrast and error correction levels for guaranteed scan success.

## ⚙️ Technical Architecture & Stack (For Developers)
The studio employs a robust, modern full-stack architecture:
*   **Frontend:** React & TypeScript, styled with Tailwind CSS.
*   **Desktop Shell:** Electron, ensuring native cross-platform deployment.
*   **Backend API:** Node.js/Express server managing data flow and AI integration.
